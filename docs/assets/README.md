# the little visual kit

self-contained svg illustrations shared by the readme, architecture, compatibility,
and github pages. no external fonts, scripts, or raster dependencies.

| piece | job |
|---|---|
| `flexe-banner.svg` | wordmark and a friendly illustrated cpu |
| `architecture-system.svg` | session ownership and subsystem connections |
| `architecture-execution.svg` | interpreter/jit dispatch and differential replay |
| `architecture-timeline.svg` | cooperative cores, deadlines, and instruction accounting |
| `compatibility-gate.svg` | scenario validation and support boundaries |

palette: navy `#0a0a1e`, panels `#12122e`, mint `#50fa7b`, lilac `#bd93f9`,
cyan `#8be9fd`, warm yellow `#ffd78b`. use a faint 48-pixel grid, rounded
panels, lowercase labels, and readable body text. each svg has a title and
description; markdown embeds also have alt text. the cpu is an illustration,
not a firmware screenshot. diagram ordering is conceptual, not a timing measurement.
